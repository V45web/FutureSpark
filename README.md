# Future Forward Website

A responsive multi-page learning website built with plain HTML, CSS, and JavaScript.

## Pages
- Home, Science, Technology & AI, Innovation, Sustainability, Future Tech, Contact Us
- Brain Quiz, Mystery Lab, Tech Challenge, Eco Mission

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish on GitHub Pages
Upload all files in this folder to the root of a GitHub repository. Open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. GitHub will provide the published site URL.

The contact form is a front-end demo and does not transmit or store messages.
